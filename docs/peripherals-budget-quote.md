# 30만원 데스크 주변기기 견적

모니터 · 키보드 · 마우스 · 조명 · 장패드 5종을 **총예산 300,000원** 안에서 구성한 견적서입니다.

- 가격 기준: 2026년 8월, 다나와 최저가 기준 근사치 (카드할인·쿠폰·배송비 제외)
- 실제 구매 시점에 가격이 오르내리므로, 결제 전 다나와/쿠팡에서 재확인 필요

---

예산을 화면에 몰아준 구성. 문서·코딩·멀티태스킹이 주 용도라면 이 조합이 체감이 가장 큽니다.

| 품목 | 추천 제품 | 핵심 스펙 | 가격 |

| 모니터 | 27" QHD IPS (알파스캔 AOC Q27 시리즈 / 한성 ULTRON 27 QHD 계열) | 2560×1440, IPS, 100Hz, 높이조절 유무 확인 | 189,000 |
| 키보드 | 앱코 K660 저소음 적축 (대안: 콕스 CK87 PBT) | 기계식, 저소음 적축, PBT 키캡 | 38,000 |
| 마우스 | 로지텍 G102 LIGHTSYNC | 유선, 8000DPI, 가벼운 85g대 | 22,000 |
| 조명 | 듀비온 라이트바 베이직 LB-01 (대안: 베이스어스 i-Wok 2세대) | 모니터 걸이형, USB 전원, 밝기·색온도 조절 | 26,000 |

## 구매 전 체크리스트

1. **"전등"을 어느 쪽으로 볼지 결정** — 화면 반사와 눈부심이 문제면 모니터 걸이형 **라이트바**, 책상 위에서 필기·서류를 본다면 **스탠드형**이 맞습니다. 견적에는 라이트바를 넣었습니다.
2. **장패드 크기** — 900×400mm가 키보드와 마우스를 한 판에 올리는 표준 사이즈입니다. 책상 깊이가 500mm 미만이면 800×300도 충분합니다.
3. **모니터 케이블 동봉 여부** — 저가 모니터는 HDMI만 주거나 아예 없는 경우가 있습니다. DP 케이블이 필요하면 5,000원 정도 별도 계산.
4. **모니터 높이조절(HAS) 지원 여부** — 미지원 모델이 많습니다. 미지원이면 모니터암(3만원대)이 사실상 필수라 총예산이 밀립니다.
5. **키보드 축 선택** — 사무실·공용 공간이면 저소음 적축, 타건감을 원하면 갈축. 청축은 소음 때문에 권하지 않습니다.
