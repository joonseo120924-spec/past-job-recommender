# 30만원 데스크 셋업 — 제품 목록 및 구매 링크

모니터 · 키보드 · 마우스 · 조명 · 장패드를 **총예산 300,000원** 안에서 구성한 견적서입니다.
모니터는 **USB-C 케이블 하나로 화면 출력과 노트북 충전이 동시에 되는(클램셸 가능)** 조건입니다.

## 링크와 가격에 대해

- 링크는 **쿠팡 검색 링크**입니다. 쿠팡이 자동 조회를 차단(403)해서 개별 상품 ID를 확인할 수 없었고, 확인하지 않은 상품 ID로 링크를 걸면 엉뚱한 물건으로 연결됩니다. 검색 링크는 모델명이 정확하므로 첫 결과가 해당 제품입니다.
- 가격은 2026년 8월 **시장 최저가 조회 기준**이며, 쿠팡 실제 판매가는 다를 수 있습니다. 배송비·카드할인 미반영.
- 이전 견적에 넣었던 앱코 K660(실제로는 광축 65,990원)과 한성 GK868B(실제로는 무접점 139,000원)는 가격대를 잘못 잡은 것이라 교체했습니다.

## 결론부터

검증된 실제 가격으로는 **B안만 30만원 안에 들어옵니다.** 모니터가 직접 충전하는 A안은 약 31만원으로 1만원가량 초과합니다.

## 결제 전 확인할 것

1. **노트북 USB-C 포트가 DP Alt Mode를 지원하는지** — 썬더볼트 포트(⚡ 표시)면 무조건 됩니다. 일반 USB-C 포트는 영상 출력을 지원하지 않는 모델이 있습니다.
2. **PD 와트가 노트북에 충분한지** — 맥북 에어는 65W로 충분, 맥북 프로 14"는 되지만 고부하 시 충전이 느립니다. 맥북 프로 16"나 게이밍 노트북은 65W로 부족해 작업 중 배터리가 줄어듭니다. 이 경우 100W가 통과하는 B안이 맞습니다.
3. **입력장치는 무선으로** — 뚜껑을 닫으면 노트북 포트 접근이 불편합니다. A안·C안의 주연테크 모니터는 USB 허브(USB-A 다운스트림) 탑재가 스펙에 명시되어 있지 않아, 무선 리시버를 꽂을 포트가 노트북 쪽에 하나 필요합니다.
4. **macOS 클램셸 조건** — 전원 + 외부 디스플레이 + 입력장치가 모두 연결된 상태에서 뚜껑을 닫고, 키보드나 마우스로 깨웁니다. 블루투스 기기라면 시스템 설정에서 *블루투스 기기의 컴퓨터 깨우기 허용*이 켜져 있어야 합니다.
5. **주사율 차이** — B안 모니터(Q27B30E)는 75Hz, A안·C안(Q27C65-120)은 120Hz입니다. 문서 작업만이면 체감이 거의 없지만 게임을 한다면 갈립니다.
6. **높이조절(HAS) 미지원** — 주연테크 Q27C65-120은 틸트(상하 각도)만 지원합니다. 눈높이가 맞지 않으면 [모니터암](https://www.coupang.com/np/search?q=%EB%AA%A8%EB%8B%88%ED%84%B0%EC%95%94%20%EC%8B%B1%EA%B8%80) 30,000원 안팎이 추가로 듭니다.
