# 30만원 데스크 주변기기 견적 (클램셸 모드)

모니터 · 키보드 · 마우스 · 조명 · 장패드를 **총예산 300,000원** 안에서 구성한 견적서입니다.
모니터는 **USB-C 케이블 하나로 영상 출력과 노트북 충전이 동시에 되는(클램셸 가능)** 조건을 만족해야 합니다.

- 가격 기준: 2026년 8월, 다나와 최저가 기준 근사치 (카드할인·쿠폰·배송비 제외)
- 실제 구매 시점에 가격이 오르내리므로, 결제 전 다나와/쿠팡에서 재확인 필요

## 조건이 바뀌면서 생긴 문제

USB-C PD를 지원하는 27" QHD 모니터의 최저가가 **249,000원**(주연테크 Q27C65-120)입니다.
총예산의 83%를 모니터 하나가 가져가므로, **나머지 네 가지에 쓸 수 있는 돈은 51,000원**입니다.
다 채울 수는 있지만 키보드·마우스가 최저가 등급으로 내려갑니다.

그래서 두 가지 길이 있습니다. A안은 요구사항 그대로, B안은 같은 클램셸 환경을 USB-C 도킹 허브로 만들어 모니터 예산을 아끼는 쪽입니다.

## 결제 전 확인할 것

1. **노트북 USB-C 포트가 DP Alt Mode를 지원하는지** — 썬더볼트 포트(⚡ 표시)면 무조건 됩니다. 일반 USB-C 포트는 영상 출력을 지원하지 않는 모델이 있어 사양표 확인이 필요합니다.
2. **PD 와트가 노트북에 충분한지** — 맥북 에어는 65W로 충분하고, 맥북 프로 14"는 되지만 고부하 시 충전이 느립니다. 맥북 프로 16"나 게이밍 노트북은 65W로 부족해 작업 중 배터리가 줄어듭니다. 이 경우 B안이 맞습니다.
3. **입력장치는 무선으로** — 뚜껑을 닫은 상태에서는 노트북 포트 접근이 불편합니다. A안 모니터는 USB 허브(USB-A 다운스트림) 탑재가 명시되어 있지 않으므로, 유선 키보드·마우스는 권하지 않습니다.
4. **macOS 클램셸 조건** — 전원 + 외부 디스플레이 + 입력장치가 모두 연결된 상태에서 뚜껑을 닫고, 키보드나 마우스로 깨웁니다. 블루투스 기기를 쓴다면 시스템 설정에서 *블루투스 기기의 컴퓨터 깨우기 허용*이 켜져 있어야 합니다.
5. **높이조절(HAS) 미지원** — 주연테크 Q27C65-120은 틸트(상하 각도)만 지원합니다. 눈높이가 맞지 않으면 모니터암 30,000원이 추가로 듭니다.
6. **장패드 크기** — 900×400mm가 키보드와 마우스를 한 판에 올리는 표준입니다. 책상 깊이가 500mm 미만이면 800×300으로 충분합니다.
