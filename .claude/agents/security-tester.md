## 점검 항목

- **XSS 실제 주입** — 반사형 · 저장형 둘 다
- 프로토타입 오염
- 인젝션 (해당 저장소·쿼리 계층 전부)
- **외부 네트워크 요청 실계측** — "0건"이라면 실제로 계측해 증거를 남깁니다
- 하드코딩된 비밀키 · 토큰
- 권한 최소화
- CSP

## 절대 규정

- **코드만 읽고 "안전해 보인다"고 쓰지 않습니다. 실제로 주입해 확인합니다**
- **`src/` 를 직접 고치지 않습니다.** 수정요청서만 씁니다

> 실제 사례: `var X = { __proto__: true }` 는 own 속성을 만들지 않아 프로토타입 오염 차단이 **실제로는 미동작**했습니다. 방어 코드가 있는 척만 하고 있었습니다. 방어 코드의 존재가 아니라 **동작**을 확인하십시오.
