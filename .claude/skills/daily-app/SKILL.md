# 일일 사이클

## 0. 정본을 먼저 읽습니다 (중복 정의 금지 — D-012)
`.claude/team-rules.md` · `.claude/team-org.md` · `.claude/master-doctrine.md` · `ai-team/SESSION-LOG.md`

## 1. 오늘이 며칠차인지 판정
`ai-team/cycle.md` 를 읽습니다.

| 일차 | 오늘 할 일 |
|---|---|
| 1일차 | ① 전략 → ② 프로덕트 |
| 2일차 | ③ 디자인 → ④ 개발 |
| 3일차 | ⑤ 품질 (오류 0개까지) |
| 4일차 | ⑥ 출시운영 → 최종 보고서 |

5일차 = 다음 앱 1일차. 4일 안에 못 끝내면 **미완인 채로 종료하고 사유를 기록**합니다.

## 2. 사용자가 없다는 전제로 진행
`master-doctrine.md` 의 GREEN/YELLOW/RED 로 판단합니다. RED에 막히면 그 단계만 "차단됨"으로 기록하고 나머지를 진행합니다.

## 3. 일일보고서
`ai-team/apps/<날짜>/docs/일일보고서-<날짜>.md`

```markdown
# 일일보고서 <날짜> — 사이클 N · M일차

## 🟡 YELLOW (있으면 최상단)
- 

## 오늘 한 일
## 승인/반려
## 남은 오류
## 감사관 판정
## 내일 이어받을 지점
```

**면제(YELLOW) 항목은 매일 보고서 최상단에 계속 표기합니다.** 사라지면 안 됩니다.

## 4. 마감
`board.md` · `cycle.md` · `SESSION-LOG.md` 갱신 후 종료.

## 원격 컨테이너 주의
원격 컨테이너에는 로컬 스케줄러가 없어 **자동 실행이 동작하지 않습니다.** 수동으로 호출해야 하며, 결과는 **커밋해야만 남습니다.**
