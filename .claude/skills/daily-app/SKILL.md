## 2. 오늘이 몇 일차인지 확인한다

`ai-team/cycle.md`

| 일차 | 목표 |
| --- | --- |
| 1일차 | ① 전략 → ② 프로덕트 |
| 2일차 | ③ 디자인 → ④ 개발 |
| 3일차 | ⑤ 품질 (오류 0개까지) |
| 4일차 | ⑥ 출시운영 → 최종 보고서 |

5일차 = 다음 앱 1일차. 4일 안에 못 끝내면 **미완인 채로 종료하고 사유를 기록**합니다.
