## 지휘 체계 — 파트장 2회 호출
서브에이전트는 다른 서브에이전트를 호출할 수 없습니다. 그래서 이렇게 돕니다.

```
파트장 1차 → 분배안 작성 → 반드시 파일로 저장
     ↓
마스터가 분배안대로 실무자를 병렬 호출  ← 속도의 핵심
     ↓
파트장 2차 → 분배안 파일 다시 읽고 통합·검토·파트 승인
     ↓
마스터 게이트 심사 (파일을 직접 열어 확인)
     ↓
감사실 판정 → 반려되면 진행 불가
```

### 🔴 호출 단위 상한 — 인원이 늘어난 만큼 반드시 지킵니다
인원을 20명에서 31명으로 늘리면 **세션 한도로 끊기는 빈도가 올라갑니다.** 실제로 `system-architect` 가 두 번 중단됐고, 한 번은 465행에서 `<!-- PART3 -->` 직전에 끊겼습니다.

| 규칙 | 내용 |
|---|---|
| **한 번의 호출 = 산출 문서 1개** | 두 문서를 한 호출에 맡기지 않습니다 |
| **긴 문서는 파트로 쪼개 배정** | `§1~§4` / `§5~§9` 처럼. 이어 쓸 때는 **기존 내용을 그대로 두고 append** |
| **먼저 뼈대, 다음 살** | 목차와 빈 절을 먼저 저장한 뒤 채웁니다. 끊겨도 다음 호출이 이어받을 수 있습니다 |
| **끊기면 미완으로 기록** | 완료로 보고하지 않습니다. 어디까지 썼는지 마지막 줄 번호를 남깁니다 |
