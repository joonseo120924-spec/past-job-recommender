## D-032 상세 — 자비스 상주 프로그램

**지시 원문 (2026-08-29)**: "박수 감지기 … 이거 할께 이거 하면 아이언맨의 자비스처럼할 수 있잖아" / "컴퓨터에서 파이썬깔고 박수익신하는 거로할께 핸드폰은 괜찮아 이거 가이드 알려줘"

### 무엇이 달라졌나
종전 `clap-listen.py` 는 **박수를 감지해 키를 누르는 도구**였습니다. 요청은 **부르면 대답하는 비서**였습니다. 그래서 다시 지었습니다.

| | 종전 | 지금 |
|---|---|---|
| 깨어남 | 키만 전송 | **"네, 사장님." 하고 소리로 대답** |
| 보고 | 별도 스크립트 | 대기 보고문을 **깨어날 때 읽음** |
| 점검 | 없음 | `--setup` 부팅 점검 (마이크·음성·단축키·보고문) |
| 보정 | `--calibrate` 수치만 | `--tune` — **권장값 계산 후 저장까지** |
| 설정 | 매번 인자로 | `jarvis.config.json` (인사말도 바꿀 수 있음) |
| 파일 수 | 2개 (갈라질 위험) | **1개** — `clap-listen.py` 흡수 |

**말하기에 추가 설치가 없습니다.** Windows 내장 SAPI 를 PowerShell 로 부릅니다 (`subprocess` + stdin 전달 → 문자열 이스케이프 문제 없음). pyttsx3 같은 의존성을 쓰지 않은 이유입니다.

**인사 뒤 0.6초 지연 후 단축키를 누릅니다** — 자비스 목소리가 받아쓰기에 섞이지 않게.

### 검증
| | |
|---|---|
| ✅ 감지 로직 | 합성 신호 **8종 전항 통과** (통합 후 재검증) |
| ✅ 설정 저장/로드 · 보고문 감지 · 부팅 화면 | 실행 확인 |
| ❌ **실제 마이크 · 실제 소리 · 단축키 전송** | 컨테이너에 오디오 장치·PowerShell 없음 |

### 가이드
`ai-team/JARVIS-설치.md` — 파이썬 설치부터 자동 시작 등록까지 7단계. **각 단계마다 실패 증상과 해결**을 붙였습니다 (PATH 미체크, pip 없음, 마이크 ○, 감도 문제).

## D-031 상세 — 기기 간 이동 · 음성 브리핑 콘솔

**지시 원문 (2026-08-29)**: "아니면 TAP모드를 항상 키고 있을 수는 없어? … 내 핸드폰이랑 컴퓨터랑 오가면서 음성이 오가고 이 팀도 오가면 좋겠어"

### 1) tap 모드 — **이미 항상 켜져 있습니다**
`voice.mode: "tap"` 은 한 번 켜면 유지되는 설정입니다. 「항상 켜 둘 수 없나」의 실제 의미는 「키를 안 누르고 시작할 수 없나」이고, **그건 불가능**합니다. 박수 감지기는 그 키 누름을 대신할 뿐입니다. → **tap 모드만 켜도 대부분 해결됩니다.**

### 2) 팀 이동 — **이미 되고 있었습니다. 새로 만든 것 없음**
핸드폰 claude.ai 앱은 **같은 원격 컨테이너**에 붙습니다. 같은 저장소 = 같은 31명 + 같은 훅 + 같은 슈퍼베이스 상태.
D-023(슈퍼베이스)·D-026(훅)이 이미 해 둔 일이며, 이번에 확인만 했습니다. **없는 일을 새로 했다고 적지 않습니다.**

### 3) 음성 **출력**이 진짜 구멍이었습니다
`speak-report.ps1` 은 Windows 전용 → 핸드폰에서 못 씁니다.
→ **브라우저 자체 음성 엔진(Web Speech API)** 을 쓰는 아티팩트를 발행했습니다. 설치 불필요, 양쪽에서 동작.

| 설계 판단 | 이유 |
|---|---|
| 슈퍼베이스를 페이지가 직접 조회? | ❌ **불가** — 아티팩트는 외부 fetch 가 CSP 로 차단됩니다. 상태를 **발행 시점에 박아** 넣고, 바뀌면 자비스가 재발행 |
| 받아쓴 말을 자비스에게 전송? | ❌ **불가** — 같은 이유. 복사·붙여넣기 또는 Claude 앱 마이크로 |
| MCP 커넥터 능력 사용? | 이번엔 **선언하지 않음** — 뷰어 동의가 필요하고 공유가 막히는데, 브리핑 낭독에는 필요 없습니다 |

**한계를 페이지 안에 적었습니다** — 못 하는 일을 사용자가 페이지에서 바로 읽을 수 있어야 합니다.
원본은 `ai-team/console/jarvis-console.html` 로 저장소에 두어 함께 버전 관리됩니다.

## D-030 상세 — 박수 감지기 · 음성 응답 루프

**지시 원문 (2026-08-29)**: "박수 감지기 제작 … 이거 해줘 그리고 내가 박수 치고 음성으로 명령하면 음성으로 답해줘"

**전제 확인**: D-029 에서 「박수 두 번·상시 마이크」는 **Claude Code 기능이 아니다** 라고 판정했습니다. 그 판정은 유효합니다. 이번에 만든 것은 **Claude Code 밖에서 그 구멍을 메우는 외부 프로그램**입니다.

### 만든 것
| 파일 | 무엇 | 필요한 것 |
|---|---|---|
| `ai-team/scripts/clap-listen.py` | 박수 두 번 감지 → 단축키 전송 | **Python + sounddevice** (설치는 사용자) |
| `ai-team/scripts/jarvis-voice.ps1` | pull → 새 보고문 SAPI 낭독 | PowerShell만 (Windows 기본) |
| `ai-team/voice-out/` | 자비스가 쓰는 **낭독 원고** 폴더 | — |

### 감지 설계 — 온셋 **AND** 감쇠
| 조건 | 거르는 것 |
|---|---|
| 온셋 (직전 블록이 조용) | 지속음이 **끝나는** 순간 |
| 감쇠 (40ms 뒤 35% 아래) | 말소리·음악 |
| 불응기 0.12s · 간격 0.15~1.2s · 재무장 3s | 중복 계수·연타 |

**검증에서 결함 1건을 잡아 고쳤습니다.** 첫 판은 감쇠만 봐서 **말소리가 끝나는 순간을 박수 1회로** 세었습니다. 합성 신호 테스트가 잡아냈고, 온셋 조건으로 해소했습니다. 8종 전항 통과.
