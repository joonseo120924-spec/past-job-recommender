#### 폐기된 잠정값 3건 — `frontend-dev` 는 아래를 그대로 따르십시오

**① Q-028 — 변수를 분리하지 마십시오.** 정본이 `--jr-tabbar-h: 56px` **하나**를 「안전영역 **제외** 높이」로 통일했고, **세 곳이 이 의미를 공유**합니다:

```css
--jr-tabbar-h: 56px;                                                     /* 안전영역 제외 */
.jr-tabbar { height: calc(var(--jr-tabbar-h) + env(safe-area-inset-bottom, 0px)); }
body       { padding-bottom: calc(var(--jr-tabbar-h) + var(--jr-sp-4) + env(safe-area-inset-bottom, 0px)); }
.jr-toast  { bottom: calc(var(--jr-tabbar-h) + var(--jr-sp-2) + env(safe-area-inset-bottom, 0px)); }
```

S-02 는 `<body data-screen="s02">` 에 `--jr-tabbar-h: 0` 이 걸려 위 세 식이 **자동으로** `0 + n + env` 가 됩니다. **별도 선언을 만들지 마십시오.**

**② Q-034 — 아이콘을 그리지 마십시오. 정본 §4-9 마크업을 그대로 옮기십시오.**
③ 이 `<nav aria-label="주요 화면">` + `<button type="button" class="jr-tab">` × 3 + **홈·통계·설정 SVG 3개**를 전부 수록했습니다(`ui-designer` 원본을 파트장이 검토·승인한 것). **`TAB_ICONS` 상수도 만들지 마십시오** — 아이콘은 `index.html` 정적 마크업입니다. `<span>` 라벨이 접근 가능한 이름이므로 **아이콘만 있는 탭을 만들지 마십시오.** `<a href="#">` 금지 사유도 정본에 있습니다(히스토리 항목이 생겨 뒤로가기 규칙과 경합).

**③ Q-033 — 토스트는 「상시 DOM + `textContent` 교체」입니다. 노드를 만들었다 지우지 마십시오.**
라이브 리전은 **이미 존재하는** 영역의 변화만 알립니다. 빈 노드를 그때그때 생성·삭제하면 **낭독되지 않습니다.** 숨김은 반드시 **`opacity`** 로 하십시오 — `display:none`·`visibility:hidden` 은 요소를 접근성 트리에서 **제거**해 라이브 리전을 죽입니다. 숨은 동안 **`pointer-events:none`** 필수(빈 토스트가 화면 하단 클릭을 가로챕니다 — `#jr-unsupported` 와 같은 함정).

- **§3-1 월별 키 분할은 하지 않습니다.** 「미리 최적화하지 않습니다」(§4-4) 그대로.
- **부수 검증**: `allocatePercents` 의 `percent` 합이 **전 시나리오에서 정확히 100** — 최대잔여법 구현이 §4-3 검산표(두 번째 표)와 일치합니다.
- **1,000건 = 129,972자** — 설계 추정 「약 130,000자」와 **오차 0.02%**. §3-5 산정이 정확했습니다.
- Firefox 수치가 정수인 것은 `performance.now()` 가 **1ms 로 절사**되기 때문입니다(타이머 정밀도 축소). Firefox 값은 **상한으로만** 읽으십시오.

## 5. 공유 계약 — 양쪽에 동일하게 넘깁니다

### 5-1. 전역 `JR` 네임스페이스 분할

```
JR.err     → fullstack-dev     JR.stats  → fullstack-dev
JR.store   → fullstack-dev     JR.io     → fullstack-dev
JR.model   → fullstack-dev     JR.ui     → frontend-dev
```

**전역은 `JR` 하나뿐입니다.** 다른 전역 변수·함수를 만들지 마십시오. 각 파일 첫 줄은 동일하게:

```js
var JR = JR || {};
JR.<모듈> = (function () { 'use strict'; /* ... */ return { /* 공개 API */ }; })();
```

### 5-2. `{ok}` 반환 규약 — 전 모듈 동일

```
성공: { ok: true,  data: <객체> }
실패: { ok: false, code: 'E-xxx', data: <객체> }
```

- `ok` 는 **boolean 리터럴**. truthy 로 대신하지 않습니다.
- 성공 시 `data` 는 **항상 객체**(값 하나여도 `{count:3}`). 배열·원시값 그대로 반환 금지.
- 실패 시에도 `data` 는 객체(비면 `{}`). 문구 치환값은 **`data.params`**.
- **예외를 던지지 않습니다.** 전 공개 함수 `try/catch`, 예상 못 한 예외는 **`E-501`**.
- 반환된 객체·배열은 **읽기 전용 취급**(R-7). `frontend-dev` 가 `e.amount = 0` 처럼 직접 대입하면 **데이터가 오염됩니다.** 반드시 `updateExpense`.
- 검증 실패는 **모든 오류를 모아** 반환:
  `{ok:false, code:'E-101', data:{errors:[{field:'amount',code:'E-101',params:{}}, …]}}`
  `field` 는 **`'date' | 'amount' | 'categoryId' | 'memo' | 'name'` 5종뿐**입니다.

**`{ok}` 로 감싸지 **않는** 함수는 정확히 12개** — 이 목록에 **추가하지 마십시오**:

| 순수 계산 9 | `model.today` · `minDate` · `maxDate` · `countChars` · `normName` · `shiftMonth` · `monthRange` · `stats.allocatePercents` · `stats.formatAmount` |
|---|---|
| **상태 조회 3** | `store.mode()` · `model.isReady()` · `model.isNoticeDismissed()` |

> **파트장 주의 — 13번째가 있습니다.** `JR.ui.lock(actionKey)` 는 §6-5 코드상 **boolean 을 반환**합니다(`if (!JR.ui.lock('save'))`). 위 12개 목록은 **하위 모듈 계약**이라 `JR.ui` 를 포함하지 않으므로 모순은 아니지만, 문서상 명시가 없습니다. **`JR.ui.lock`/`unlock` 은 boolean 반환으로 구현하십시오**(§5-4). → Q-039.

> ### ⚠️ 파트장이 대조 중 찾은 **키 이름 충돌 1건** — `getCategories()`

> 두 문서가 **같은 함수의 `data` 키를 다르게** 적었습니다. 두 사람이 각각 다른 문서를 보면 **`frontend-dev` 의 렌더가 조용히 빈 목록을 그립니다.**

### 5-3. 의존 방향 — 역방향 호출은 **1건만** 허용

```
err ← store ← model ← stats
 ↑      ↑       ↑   ↖    ↑
 └──────┴───────┴──── io ┘
                ↑
               ui  (전부 읽음. 하위 모듈은 ui 를 부르지 않는다)
```

| 모듈 | 불러도 되는 것 | **절대 금지** |
|---|---|---|
| `JR.err` | 없음 (순수) | 전부 |
| `JR.store` | `err` | `model`·`stats`·`io`·`ui` |
| `JR.model` | `err`·`store` + **`stats.invalidate` (예외 1건)** | `io`·`ui` |
| `JR.stats` | `err`·`model`(읽기 전용만) | `store`·`io`·`ui` |
| `JR.io` | `err`·`store`·`model` | `ui` · **`stats`(INT-24 로 금지 명시)** |
| `JR.ui` | 전부 | — |

**유일한 역방향**: `JR.model` 의 쓰기 함수가 성공 직후 `JR.stats.invalidate()` 를 직접 호출. `stats.js` 가 뒤에 로드되므로 **존재 확인 후** 호출:

```js
function notifyChange(kind) {                 // 'expense'|'category'|'settings'|'bulk'
  if (JR.stats && typeof JR.stats.invalidate === 'function') JR.stats.invalidate();
  for (var i = 0; i < subscribers.length; i++) {
    try { subscribers[i](kind); } catch (e) { JR.err.log('E-501', e); }
  }
}
```

> **`JR.ui` 는 `subscribe` 로만 변경을 통지받습니다.** 하위 모듈이 `JR.ui` 를 직접 부르는 코드를 쓰지 마십시오.

| **`JR.ui.show(code, params, field)`** | | **INT-15 · 필수.** 모든 E-코드 표시의 **단일 경로** |
| `JR.ui.toast(code, params)` | | T. 교체(누적 없음), **`JR.ui.TOAST_MS`=3000** 자동 소멸 |
| `JR.ui.inline(field, code, params)` | | I. `code === null` 이면 그 필드 인라인 오류 **제거** |
| `JR.ui.banner(code, params)` | | B. 같은 코드 배너가 있으면 **다시 만들지 않음** |
| `JR.ui.dismissBanner(code)` | | 배너 닫기. §7-8 규칙에 따라 `JR.model.dismissNotice` 호출 여부가 갈림 |
| `JR.ui.lock(actionKey)` | → **boolean** | `'save'\|'delete'\|'export'\|'import'\|'wipe'\|'category-add'`. 이미 잠겼으면 `false` |
| `JR.ui.unlock(actionKey)` | | |
| `JR.ui.MSG` | 상수 객체 | 아래 **10종** |
| `JR.ui.TOAST_MS` | `3000` | INT-33 · 단일 상수 |

**`show()` 는 이렇게 구현합니다 (슬롯 판정을 호출부가 하지 않습니다):**

```js
JR.ui.show = function (code, params, field) {
  var s = JR.err.slot(code);
  if (s === 'I') return JR.ui.inline(field || JR.err.get(code).field, code, params);
  if (s === 'B') return JR.ui.banner(code, params);
  return JR.ui.toast(code, params);
};
```

> **`JR.err.slot(code)` 이 `'B'` 인데 `JR.ui.toast(code)` 를 부르면 계약 위반입니다.** `E-413` 이 정확히 이 경우입니다 — INT-32 로 T→B 가 되었고, `show()` 를 쓰면 **호출부 0줄 변경**으로 자동 반영됩니다.
