## Loop Habit Tracker
- 플랫폼 / 평점 / 리뷰 수: Android(F-Droid/Google Play), 4.72/5, 약 61,000건 평점, 누적 다운로드 약 760만 (2026-08-10 확인) — [AppBrain](https://www.appbrain.com/app/loop-habit-tracker/org.isoron.uhabits), [F-Droid](https://f-droid.org/packages/org.isoron.uhabits/), [Google Play](https://play.google.com/store/apps/details?id=org.isoron.uhabits&hl=en_US)

- 페이월: **없음.** 광고·인앱결제·유료 기능 전무 — 전 기능이 처음부터 무료. 다만 클라우드 백업이 없어 기기 변경 시 수동 export/import 필요 ([AppBrain](https://www.appbrain.com/app/loop-habit-tracker/org.isoron.uhabits), [F-Droid](https://f-droid.org/packages/org.isoron.uhabits/), 2026-08-10).

- 약점(리뷰 근거): "Android only, no social features, no cloud backup, and a utilitarian interface that won't win design awards" — 습관을 그룹/폴더로 묶는 기능 부재, 타이머·스톱워치 기능 없음. 클라우드 백업 없어 수동 export 필요 ([productivity.directory 리뷰](https://productivity.directory/loop-habit-tracker), 2026-08-10).

- 페이월: **기록·통계·다중계좌 등 핵심 기능은 무료.** 화면 하단 배너 광고가 상시 노출되며, **광고 제거 + 다크테마 등은 "Premium" 별도 앱/인앱결제(1회성 구매, 구독 아님)**로 잠금 ([Google Play](https://play.google.com/store/apps/details?id=com.realbyteapps.moneymanagerfree&hl=en_US), 2026-08-10).

# C. 암기 플래시카드 (간격반복 SRS)

## Anki (데스크톱/AnkiWeb/AnkiDroid) vs AnkiMobile(iOS)
- 플랫폼 / 평점 / 리뷰 수:
  - Windows/Mac/Linux 데스크톱 + AnkiWeb: 무료, 별도 스토어 평점 없음(오픈소스 배포)
  - AnkiDroid(Android): 4.8/5, 약 151,000건 리뷰 (2026-08-10 확인) — [FlashRecall 인용, Google Play 기준](https://flashrecall.app/blog/ankidroid-google-play)
  - AnkiMobile(iOS): 4.0/5, 약 2,300건 평점 (2026-08-10 확인) — [App Store](https://apps.apple.com/us/app/ankimobile-flashcards/id373493387)
- 핵심 기능: 사용자가 카드덱 직접 제작, SM2/FSRS 간격반복 알고리즘, 미디어(이미지/오디오) 첨부, 애드온 생태계, 기기 간 동기화(AnkiWeb).
- 페이월: **데스크톱·AnkiWeb·AnkiDroid(Android)는 완전 무료**(동기화 포함). **iOS만 예외적으로 AnkiMobile $24.99 1회 결제**가 유일한 공식 앱 — iPhone에서 진짜 SRS(FSRS/SM2)를 쓰려면 이 결제가 필요하고, 무료 대안은 Safari로 ankiweb.net 접속뿐인데 "real 간격반복이 아니며 review cycle이 단순화됨" ([flashcardslearn.com](https://www.flashcardslearn.com/en/blog/how-much-does-anki-cost), [cuadernote.com](https://cuadernote.com/en/blog/is-anki-free-on-ios/), 2026-08-10).
- 강점: 알고리즘 품질(FSRS)이 업계 표준급, 완전 오프라인 동작 가능, 오픈소스로 데이터 락인 없음, 데스크톱/Android는 100% 무료.
- 약점(리뷰 근거): iOS 사용자는 "so freaking expensive for an app"이라며 환불 요청 다수, 개발자는 "가격을 낮췄더니 오히려 수익이 줄어서" 유지한다고 공식 해명. 그 외 "slow syncing that doesn't work properly", "loss of media from previous cards" 등 동기화 버그 불만 존재 ([justuseapp.com 리뷰](https://justuseapp.com/en/app/373493387/ankimobile-flashcards/reviews), [Anki 공식 FAQ](https://faqs.ankiweb.net/why-does-ankimobile-cost-more-than-a-typical-mobile-app.html), 2026-08-10). 학습 곡선이 가파르다는 지적도 반복됨.

Plus는 $7.99/월(또는 $2.99~3.74/월 단계별 요금제로 라운드 수 제한 차등), 완전 무제한은 Plus Unlimited($44.99/년 등) ([brighterly.com](https://brighterly.com/blog/quizlet-cost/), [aistudymaster.com](https://aistudymaster.com/quizlet-plus-cost/), 2026-08-10).

"cannot go thirty seconds without being inundated with ads and pop-ups for Quizlet Plus". "charged immediately despite being promised a 7-day free trial" 등 결제 관련 불만이 Trustpilot 1.4/5의 주요 원인으로 지목됨 ([Trustpilot](https://www.trustpilot.com/review/www.quizlet.com), 2026-08-10).

# D. 텍스트 유틸리티 툴박스 (마크다운/JSON/YAML/단위변환/diff)

## DevToys (+ DevToys Web Pro)
- 플랫폼 / 평점 / 리뷰 수: Windows/Mac/Linux 데스크톱 + 웹/PWA + 브라우저 확장, 오픈소스(GitHub, MS Store 배포) — 스토어 통합 평점 수치는 확인 불가(리포지토리·MS Store 분산 배포로 단일 평점 없음, 2026-08-10 확인 시도) — [devtoys.app](https://devtoys.app/), [GitHub](https://github.com/DevToys-app/DevToys)
- 핵심 기능: JSON/XML/SQL/YAML/HTML 포매터, Base64/URL/JWT/GZip 인코더, 해시·UUID·비밀번호 생성기, 정규식/JSON Schema 테스터, 텍스트 diff, 마크다운 미리보기, 40개 이상 도구 모음, 스마트 감지(붙여넣기 시 자동으로 알맞은 도구 제안).
- 페이월: **없음.** 전 기능 무료, 로그인 불필요, 완전 오프라인 동작(웹 버전도 "processes everything locally... no data is transmitted... continue working offline after the page loads") — 유료 티어 자체가 존재하지 않음 ([devtoys.pro](https://devtoys.pro/), [xda-developers 리뷰](https://www.xda-developers.com/devtoys-replaced-a-lot-of-my-bookmarks-and-it-works-entirely-offline/), 2026-08-10).
- 강점: 도구 개수와 통합도가 높음, 로컬 처리로 즉각 반응, "붙여넣으면 알아서 도구 추천"하는 UX 호평.
- 약점(리뷰 근거): 구체적 부정 리뷰는 검색상 발견되지 않음(오픈소스 도구 특성상 스토어 리뷰 생태계가 얕음) — **"약점 특이사항 없음, 미검증"으로 명시**. 다만 데스크톱 앱 설치가 기본이라 모바일 사용성은 상대적으로 약함(추정 — 공식 리뷰 근거 아님).

## IT-Tools (it-tools.tech)

## CyberChef (GCHQ 원본 + cyberchef.dev 파생 서비스)
- 플랫폼 / 평점 / 리뷰 수: 웹, 정량 평점 데이터 없음(오픈소스 툴, 스토어 미등록) — [cyberchef.dev](https://www.cyberchef.dev/), [GCHQ 원본](https://gchq.github.io/CyberChef/)

- 페이월: **없음.** 전 기능 무료, "no data uploaded", 설치 없이 브라우저에서 즉시 사용.
- 강점: 도구 수가 매우 많고 보안/포렌식 영역까지 커버, 완전 무료.
- 약점(리뷰 근거): 정량 리뷰 데이터 확인 불가(스토어 미등록) — **"확인 불가"로 명시**. UI가 파워유저 지향이라 초심자에게는 복잡하다는 일반적 평가가 존재하나 이 앱 특정 리뷰 인용은 찾지 못함(추정).

**D 카테고리 종합 메모**: DevToys·IT-Tools·CyberChef 모두 **이미 완전 무료·오프라인 가능·무광고**로 운영 중인 강력한 오픈소스 경쟁자가 존재함. 즉 후보 D는 "무료·오프라인"이라는 축만으로는 차별화가 거의 안 되고, UX/통합도/한국어 지원 등 다른 축에서 승부해야 함 (종합 판단은 파트장 몫이므로 여기서는 사실만 기재).

# 해석 — "돈 안 받는 정적 오프라인 버전"으로 차별화 여지 순위

(최종 판단 아님 — 종합 단계 재료 제공용. 배점표의 "차별점(25점)" 근거로만 사용)

1. **1위: B(가계부/지출 계산기)** — 조사한 경쟁 앱 전부(Money Manager, Spending Tracker 등)가 **광고 노출 또는 인앱결제로 광고 제거**를 요구하며, 특히 광고 관련 불만("can't close the ads", "covers the whole screen")이 실제 리뷰에서 반복 확인됨. "광고 0 + 결제 0" 버전은 기존 앱의 가장 직접적인 불만 지점을 그대로 제거하는 구조라 차별화가 뚜렷함.
2. **2위: A(습관 트래커)** — Loop Habit Tracker가 이미 완전 무료·오프라인이라는 강력한 경쟁자지만 Android 전용이고 클라우드 백업이 없음. Streaks는 iOS 전용 유료, Habitica는 무료지만 계정/동기화 기반이라 완전 오프라인이 아님. "크로스 플랫폼 + 완전 오프라인 + 무료"의 조합을 이미 채우는 경쟁자는 없어 틈새가 있음.
3. **3위: E(레시피&장보기)** — Paprika(1회 결제, 플랫폼별 재구매), AnyList(웹 레시피 가져오기 5건 제한)는 명확한 페이월이 있으나, Mealime은 이미 무료 등급이 상당히 관대해 "무료"만으로는 차별화 폭이 좁음. 다만 Mealime도 계정 로그인 기반(완전 오프라인 아님)이라는 점은 차별화 여지로 남음(2026-08-10 조사 기준 Mealime의 계정 요구 여부는 직접 확인 못함 — 확인 불가).
4. **4위: C(플래시카드 SRS)** — iOS의 AnkiMobile($24.99)과 Quizlet(파상적 페이월·광고 불만)은 페이월이 뚜렷해 차별화 여지가 크지만, Anki 데스크톱/AnkiDroid가 이미 완전 무료·오픈소스로 존재하기 때문에 "이미 무료 강자가 있는 곳에 무료로 진입"하는 셈이라 상대적으로 신선도가 낮음. iOS 사용자 한정으로는 차별화 여지가 크다는 점은 유의.
5. **5위: D(텍스트 유틸리티 툴박스)** — DevToys·IT-Tools·CyberChef가 이미 **광고 없음·로그인 없음·완전 무료·오프라인 가능**을 모두 충족하고 있어, "무료·오프라인"이라는 축 자체로는 차별화가 거의 없음. 이 카테고리에서 승부하려면 무료/오프라인이 아닌 다른 축(UX 간결함, 특정 도구 조합, 한국어 등)이 필요.
