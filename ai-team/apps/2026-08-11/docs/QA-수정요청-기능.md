## F-001 · 내보내기 대체 영역이 S-04 를 벗어나도 접히지 않아, 다시 들어오면 누르지도 않은 JSON 전문이 떠 있습니다

- **결함 ID / 심각도**: `QA-F-001` · **S3 경미**
- **대상**: `src/js/ui.js:993~1001` (`#jr-export-fallback`) · INT-10 / INT-39 · F-08
- **전제**: Chromium · Firefox · WebKit **3엔진 전부** · 사이클 1~20 전부 · 기록 1건 이상

**재현**
1. 지출을 1건 이상 저장한다 (예: 메모 `점심 김치찌개`, 12,500원)
2. 설정 탭(S-04) → **[내보내기]** 를 1회 누른다 → 대체 영역이 펼쳐지고 `#jr-export-text` 에 전체 기록 JSON 909자가 담긴다
3. 홈 탭(S-01) 으로 나간다
4. 다시 설정 탭(S-04) 으로 들어온다 — **[내보내기] 를 누르지 않는다**

**기대** — INT-10 확정: 「영역은 S-04 를 벗어나면 사라지고, **다시 [내보내기] 를 누르면** 다시 나타납니다」
→ 4) 시점에 영역은 접혀 있고 `#jr-export-text` 는 비어 있어야 합니다.

**실제** — 4) 시점에 **누르지도 않았는데 높이 309px 로 펼쳐진 채 전체 기록 JSON 909자가 그대로 보입니다.** `hidden` 이 2) 이후 다시 걸리지 않습니다. **새로고침해야만** 사라집니다.

## F-002 · `ui.unlock` 이 비-`{ok}` 18번째입니다 (INT-34 정본 17개 명단 밖)

- **결함 ID / 심각도**: `QA-F-002` · **S3 경미** — *파트장 재판정 요청*
- **대상**: `src/js/ui.js:206` · INT-34 비-`{ok}` 정본 17개 명단 · 분배안 §3-1
- **전제**: 3엔진 전부 · 사이클 1~20 전부

**재현**
1. 앱을 연다
2. `err`·`store`·`model`·`stats`·`io`·`ui` 6모듈의 표면 함수 40개를 전수 호출해 반환이 `{ok:boolean}` 인지 검사한다 (`verify/qa-extra.cjs` §A)
3. 비-`{ok}` 목록을 INT-34 정본 17개 명단과 대조한다

**기대** — 분배안 §3-1: 「17개 명단 **밖**의 비-`{ok}` 함수만 보고하십시오. **18번째가 새로 발견되면 그것은 결함입니다.**」 → 명단 밖 0건

**실제** — **18개 측정. 18번째는 `ui.unlock`** (반환 `undefined`).

**증거**

**요청하는 수정 — 둘 중 하나. ⑤ 는 고르지 않습니다**

- **ⓑ 코드 정정**: `unlock` 이 `E.ok({})` 를 반환하도록 변경. **단, `ui.lock` 도 함께 바꾸지 않으면 짝이 어긋납니다.** `lock` 은 이미 예외 승인되었으므로 ⑤ 는 이쪽을 권하지 않습니다.

- **소유자 추정**: `tech-lead` (ⓐ) 또는 `frontend-dev` (ⓑ)

## F-004 · 두 창을 나란히 띄우면 다른 창의 저장이 반영되지 않습니다 — **S4 · 계약 확인 요청**

- **결함 ID / 심각도**: `QA-F-004` · **S4 개선**
- **대상**: `src/js/boot.js:167 onVisible()` · `registerLifecycleEvents()`

**재현**
1. 같은 앱을 창 A · 창 B 에 연다 (둘 다 화면에 보임)
2. 창 A 에서 지출 3건을 저장한다
3. 창 B 를 화면 전환 없이 그대로 둔다 → **반영되지 않음**
4. 창 B 를 hidden → visible 로 왕복시켜도 **반영되지 않음** (`onHidden()` 이 가려지는 순간의 `writeAt` 을 기준점으로 **다시 잡기** 때문)

**실측**
```
(탭B 를 hidden 으로 만들지 않고 A 가 쓴 뒤 왕복) FAIL | {"dom":0,"model":0,"total":"0원","toast":""}
(탭B hidden → A 가 쓰기 → B 복귀 = 현실 순서)   PASS | {"dom":0,"model":3, …}
```

**⑤ 판정: 결함이 아니라 설계 공백으로 봅니다.** 구조설계 §6-8-3 은 「**복귀 시** 데이터 재로드」만 약속하고, 두 창 동시 표시는 그 밖입니다. **계약을 넓힐지는 ② 소관** → **Q-071**.

**참고 — 만약 ② 가 넓히기로 하면** 고칠 곳은 `boot.js` 에 `window.addEventListener('storage', …)` 구독 추가입니다. 다만 그 경우 **INT-38(`E-605` 재렌더) 시정과 같은 자리를 건드리므로 함께 설계해야 합니다.**
