**`functional-tester` 는 WebKit 을 3번째 엔진으로 실제 포함하십시오.** ④ 가 못 한 것을 ⑤ 가 합니다.

## 3. 공통 기준선 — **양쪽이 글자 그대로 동일하게 적용** (어기면 오탐이 납니다)

### 3-1. ⚠️ 비-`{ok}` 함수 = **17개** (Y-3) — 그리고 **스크립트는 16 이라고 출력합니다**

**이것이 이번 분배안에서 가장 사고 나기 쉬운 자리입니다. 파트장이 직접 돌려 원인을 확정했습니다.**

`verify/ok.cjs` 를 돌리면 마지막 줄에 **`개수: 16`** 이 찍힙니다. 인계서는 **17**이라고 합니다. **둘 다 맞습니다.**

- `ok.cjs` 의 열거 루프는 **`['err','store','model','stats','io']` 5개 모듈만** 훑습니다. **`ui` 는 루프 밖**에서 따로 출력합니다(`=== JR.ui.lock 반환 타입 === boolean`).
- 즉 **16 (5개 모듈) + `ui.lock` 1개 = 17.**

**정본 17개 명단** (파트장 실행 출력 그대로):

| # | 함수 | 반환형 | 출처 |
|---|---|---|---|
| 1~3 | `err.get` · `err.slot` · `err.format` | Object · String · String | 1차에서 누락되었던 4개 중 3 |
| 4 | `store.mode` | String | 계약 12개 |
| 5 | `model.isReady` | Boolean | 계약 12개 |
| 6~12 | `model.today`·`minDate`·`maxDate`·`countChars`·`normName`·`shiftMonth`·`monthRange` | String×5 · Number · Object | 계약 12개 |
| 13 | `model.isNoticeDismissed` | Boolean | 계약 12개 |
| 14~15 | `stats.allocatePercents` · `stats.formatAmount` | Array · String | 계약 12개 |
| 16 | `stats.invalidate` | Undefined | 1차 누락 4개 중 1 |
| 17 | **`ui.lock`** | **Boolean** | Q-039 로 이미 지적됨 |

**판정 규칙 — 못박습니다.**
- **위 17개는 규약 위반이 아닙니다.** 계약 문서(분할안 §5-2)가 12개라고 적어 놓고 **같은 문서의 §5-3·§5-4 예시 코드가 그 4개를 비-`{ok}` 로 쓰라고 지시**한 **파트장 문서의 자기모순**입니다. 실무자는 예시를 정확히 따랐습니다.
- **`개수: 16` 을 보고 「인계서와 불일치」로 결함을 올리지 마십시오.** 위 설명이 원인의 전부입니다.
- **18번째가 새로 발견되면 그것은 결함입니다.** 17개 명단 밖의 비-`{ok}` 함수만 보고하십시오.

### 3-5. **성능 판정 기준선 — 1,000건** (Y-4)

### 4-2. `security-tester` 담당 — 주입·오염·계측·무결성

| 영역 | 필수 검증 |
|---|---|
| **XSS 실주입** | **말이 아니라 실제로 넣으십시오.** 메모 · 카테고리 이름 · 가져오기 JSON 의 모든 문자열 필드에 `<img src=x onerror=...>` · `<script>` · `"><svg onload=...>` · `javascript:` · 유니코드 우회. **`innerHTML` 0건이므로 `textContent` 경로가 실제로 이스케이프하는지 DOM 으로 확인**하고, **실행되면 즉시 S1** |
| **프로토타입 오염** | 가져오기 JSON 에 `__proto__` · `constructor.prototype` · `prototype` 키 주입 → **`({}).polluted` 가 오염되는지 실측**. `JSON.parse` 결과를 병합하는 전 경로(`applyImport`·`replaceAll`·설정·카테고리) |
| **네트워크 요청 실계측** | **전 기능 흐름을 돌며 `request` 이벤트를 실제로 수집**. `file://` 이외 요청 **0건**이어야 함. 1건이라도 나오면 S1. 파비콘·폰트·CSS 포함 |

| **저장소 무결성** | 키 네임스페이스 `jr.v1.*`/`jr.__probe` 외 **0건** · 손상 격리(`jr.v1.corrupt.*`)가 **원본을 지우지 않는가** · 복구 사다리 · `.bak` · 용량 초과 롤백 |
| **데이터 잔존** | `wipeAll` 후 **잔여 키 0** · 카테고리 정확히 기본 8종 · 초안 삭제 · **내보내기 파일에 예상 밖 필드가 새지 않는가** |
| **코드 실행면** | `eval`·`new Function`·문자열 타이머 · `document.write` · 인라인 이벤트 핸들러 속성 · `javascript:` href — **정적 + 런타임 양쪽** |
| **전역 오염** | `JR` 외 전역 누수 0 · 모듈 사설 상태(`monthIndex`)가 외부에서 안 보이는가 |
