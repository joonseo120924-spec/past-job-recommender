# A. 오프라인 습관 트래커

- 이탈 이유 추정: 핵심 기능(습관 개수)이 무료 한도 안에서 막혀 실사용 전 이탈 (근거: 위 인용 — "asks you for money"가 사용 흐름 중간에 등장)

## 불편사항: 기기 간 동기화를 위해 여러 계정(Apple ID+Google+이메일) 연동을 요구

## 불편사항: 게임화(펫·보상) 요소가 구독에 종속되어 있어 무료 사용자는 목표 달성이 사실상 불가능

- 이탈 이유 추정: 무료 사용자에게 동기부여 장치 자체가 무력화되어 지속 사용 유인 소멸 (근거: "there's little incentive to actually use the app")

## 참고: 계정 없는 로컬 우선 모델에 대한 커뮤니티 언급 (사용자 리뷰 아님 — 비교 블로그 서술)

- Habitica의 경우 같은 비교 글에서 "includes trackers like Google Firebase, Facebook Share and Login, and Amplitude — a reminder that just because it is open-source, doesn't mean that it respects your privacy"라는 서술도 확인 (출처: 동일 URL). 원문 게시 필자가 익명 블로그이므로 개인 사용자 리뷰로 분류하지 않음.

# D. 텍스트 유틸리티 툴박스

## 불편사항: 온라인 JSON/코드 포맷터에 붙여넣은 민감정보(API 키·비밀번호)가 서버에 저장·유출됨
- 언급 빈도: 실제 사용자 리뷰 형태는 아니나, 보안 조사 기사로 규모가 확인된 구조적 문제 — 조사 기사 1건(WatchTowr 조사 결과)
- 인용: "anything you paste into them can potentially be stored and exposed" — 도구가 온라인(서버) 방식으로 처리하기 때문에 발생하는 근본 위험이라는 취지 (출처: https://www.helpnetsecurity.com/2025/11/25/code-formatting-sites-exposing-secrets/ , 조사일: 2026-08-10, 원 기사 게재일: 2025-11-25)
- 부가 사실: WatchTowr 연구팀이 JSONFormatter·CodeBeautify 두 사이트에서 8만 건 이상의 저장된 JSON 항목을 발견했고, 그 안에는 Active Directory 자격증명, GitHub 토큰, 클라우드 액세스 키, SSH 세션 기록 등이 포함되어 있었으며, 카나리 AWS 토큰 업로드 48시간 이내에 실제 악용 시도가 관측됨 (출처: 동일 URL, 조사일: 2026-08-10)
- 사용 맥락: 개발자/직장인이 업무 중 JSON·설정 파일을 빠르게 정리하려고 검색 상위에 뜨는 온라인 포맷터에 데이터를 그대로 붙여넣는 상황 (설정 파일에는 종종 실제 키가 섞여 있음)
- 이탈 이유 추정: 사고가 발생한 이후 사용자들이 "브라우저 로컬 처리(서버 전송 없음)" 도구로 이동하는 경향이 조사·업계 권고 형태로 확인됨 (근거: 기사 내 권고 — "The recommended alternative is to use JSON formatters that run entirely in your browser, so your data never leaves your device")

## 불편사항: (참고) 온라인 텍스트 도구 자체가 "로컬 처리"를 마케팅 포인트로 강조하는 경향 — 역으로 사용자 우려가 크다는 방증
- 언급 빈도: 다수 도구 랜딩페이지에서 동일 문구 반복 확인 (정량화된 리뷰 수치 아님 — 확인 불가)
- 인용: "your data never leaves your device" (JSON to Markdown/Table 변환 도구 소개 문구) (출처: https://tableconvert.com/markdown-to-json , 조사일: 2026-08-10)
- 사용 맥락: 사용자가 도구 선택 시 "서버로 전송되지 않는다"는 문구를 신뢰 판단 기준으로 삼는 정황
