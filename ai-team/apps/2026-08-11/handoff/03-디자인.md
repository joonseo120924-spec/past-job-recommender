**개정 1차의 슬롯 변경 2건**

1. **`E-413` 이 T → B(사건형)로 옮겨졌습니다** (② 판정 · INT-32). **호출부 코드는 0줄 바뀝니다** — `JR.ui.show(code, …)` 단일 경로이므로 `JR.err` 표의 슬롯 칸만 고치면 자동으로 배너로 나갑니다. 분포는 **T 33 · I 15 · B 15 · 정적 1 = 64**(종전 T 34 · B 14).
2. **I 슬롯이 4자리 → 5자리**가 되었습니다. 「새 카테고리 추가」 경로(`E-114`·`E-115`·`E-116`)의 자리가 없어 **게이트 「슬롯 누락 0건」에 반례 1건**이 있었습니다.

- 배너는 여러 개를 쌓지 않고 **가장 심각한 것 하나만** 띄웁니다(구조설계 §7-8. **`E-413` 은 `E-410` 다음 · `E-302` 앞**, INT-32).
- **④ 구현 1건**: 가져오기 결과 배너(`E-410`·`E-411`·`E-413` **3개 전부**) 표시 직후 **`window.scrollTo({top:0})`**. 배너가 `sticky; top:0` 인데 `가져오기` 버튼이 화면 아래쪽이라 **시야 밖에서 뜹니다**(INT-32).
- **최장 문구 실측 (개정 1차 정정)**: 배너 `E-201` 95자 → 360px 에서 **5줄·143.95px**, 잘림 없음(종전 6줄·166.3px 은 배너를 열 안에 넣고 잰 값). 토스트 `E-413` 87자 → **4줄**(종전 5줄은 **패딩 24px 미차감 오산**), 잘림 없음. **적용 후 T 최장은 `E-121` 61자**(INT-33 단축)이므로 87자 값은 **상한 검증값**으로만 남습니다.
- `max-height`·`overflow:hidden` 을 배너·토스트에 **절대 걸지 마십시오** — 걸는 순간 잘림이 가능해집니다.
- **줄 수 산출식**: `(박스 높이 − 상하 패딩) ÷ 22.4`. 배너 패딩 32px · 토스트 패딩 24px. **패딩을 빼지 않아 두 값이 +1 이었습니다** — ⑤ QA 도 같은 식을 쓰십시오.

## 5. ⑤ QA 가 검증할 접근성 기준선 (④ 가 지켜야 하는 수치)

가이드 §9 가 실측 원본입니다. 요약:

| 기준 | 값 | 실측 결과 |
|---|---|---|
| 본문 텍스트 대비 | 4.5:1 이상 | 전 조합 통과, 최저 **5.26:1** |
| 비텍스트 대비 | 3:1 이상 | 통과, 실질 최저 **3.10:1** |
| 터치 영역 | 44×44px | **32/32 통과**(시정 후). ⚠️ **이 값은 최하단 스크롤을 포함하지 않았습니다** — 각 화면을 **끝까지 스크롤한 상태에서 한 번 더** 검사하십시오(가이드 §9-2 한계) |
| 인접 간격 | 8px / 파괴적 **12px** | 통과. 경계 2건(7px)·예외 2건(0px)은 가이드 §9-3 에 기록 |
| 최소 글자 | 14px | **위반 0건** |
| 포커스 표시 | 모든 조작 요소 | **누락 0건** |
| 색만으로 정보 전달 | 금지 | **0건**(5개 지점 전부 다중 신호) |
| `prefers-reduced-motion` | 대응 필수 | 확인 |

**개정 1차에서 추가된 기준선**

| 기준 | 값 |
|---|---|
| **문서 언어** | `<html lang="ko">` — 없으면 한국어 문구를 영어 음성 엔진이 읽습니다 |
| **확대 허용** | `maximum-scale`·`user-scalable=no` **금지** (WCAG 1.4.4) |
| **라이브 리전** | 토스트(`status`/`polite`/`atomic`, 상시 DOM) · 내보내기 대체 영역(`polite`) · 차단형 배너(`alert`) |
| **본문 하단 여백** | 마지막 조작 요소가 고정 탭바에 가려지지 않을 것 (히트 픽셀 > 0) |

**구현하면서 위 수치를 깨지 마십시오.** 특히 자주 깨지는 자리: ① `outline: none` 을 대체 없이 추가 ② 작은 아이콘 버튼을 44px 미만으로 추가 ③ 상태를 색만으로 표시 ④ `--jr-divider` 를 조작 요소 경계에 사용(그 자리는 `--jr-border`) ⑤ **라이브 리전을 `display:none` 으로 숨기거나 노드를 매번 새로 만들기** ⑥ **`opacity:0` 만 걸고 `pointer-events` 를 빠뜨리기**.

**대비는 개정 1차에서 파트장이 다시 계산했습니다** — 34조합(토큰 29 + 알파 합성 5) 전건 일치, **개정이 만든 새 색 0건**(가이드 §9-12).

## 8. ③ 이 하지 않은 것 — 정직하게

| 항목 | 상태 |
|---|---|
| **`frontend-dev` 교차검토** | ✅ **수행됨 (2026-08-18)** — ⚠️ 조건부 통과 · **시안 되돌림 0건** · 지적 10건 전건 이 개정에서 닫음 |
| **개정 1차 CSS 의 브라우저 실행** | ❌ **하지 못했습니다.** 파트장이 이번 호출에서 브라우저를 실행하지 못해 **대비는 재계산, 기하는 산술로만** 검증했습니다. 원시 렌더 수치는 `frontend-dev`·`tech-lead` 의 재측정을 출처와 함께 인용했습니다. 미실행 항목은 §6-3 |
| 래스터 아이콘(PNG · `apple-touch-icon`) | 만들지 않음. 래스터 금지 규칙 + 스토어 등록 미확정. 제출 단계가 오면 ⑥ 소관 |
| 다크 모드 시안 | 만들지 않음 (v2) |
| 안드로이드 어댑티브 아이콘(66% 세이프존) 검증 | 하지 않음. 정사각형 내접원 1종만 계산 |
| 실제 한글 시스템 폰트에서의 렌더 | 하지 못함 (§6-2) |

**파트장이 실측으로 검증한 범위**(초판 · 2026-08-18): Chromium 141 · 뷰포트 360px/520px · `file://` 로드 · 대비 44조합 계산(+검산 4건) + 렌더 픽셀 대조 · 히트 영역 32개 탐침 · 인접 간격 12쌍 · 글자 크기 전수 · 포커스링 · `prefers-reduced-motion` 에뮬레이션 및 대조 실험. **개정 1차**(2026-08-20): 대비 34조합 **재계산**(불일치 0건) + 기하 산술 검증. **이 범위 밖은 전부 "확인 불가"로 적었고 통과로 쓰지 않았습니다.**

**초판이 틀렸던 것 — `frontend-dev` 가 찾아 준 것들입니다. 감추지 않습니다.**

1. **「이 문서 하나만 읽고 착수할 수 있다」는 사실이 아니었습니다** — `<head>`·탭바 마크업·S-04 추가 경로에서 막혔습니다.
2. **게이트 「E-코드 64개 전부 갈 곳 있음」에 반례 1건**이 있었습니다(자기 점검표에 ✅ 로 적혀 있던 항목).
3. **터치 영역 32/32 통과가 더 큰 결함을 감쌌습니다** — 탐침 범위(최하단 스크롤 미포함)를 적지 않은 것이 원인입니다.
4. **§9 머리말의 측정 대상 서술이 실제와 달랐습니다** — 검증하지 않은 범위를 검증한 것처럼 적었습니다.
5. **§9-4 줄 수 2건이 틀렸고 그 숫자가 ② 판정 자료로 올라갔습니다** — 산출식을 적지 않아 오산이 숨었습니다.
6. **남을 지적한 항목(§10-4 아이콘 누락)에서 같은 잘못을 했습니다** — 탭 아이콘 3개를 세기만 하고 싣지 않았습니다.
