## 1. 무엇을 만드는가 — 한 눈에

**로그인 없이 기기 안에만 저장되는 수기 입력형 지출 기록 · 카테고리별 통계 앱.** 가칭 **정레**.

| 항목 | 값 |
|---|---|
| 실행 | 브라우저에서 `index.html` 을 `file://` 로 직접 열기. 서버·설치·네트워크 요청 **0건** |
| 화면 | **4개뿐** — S-01 홈 · S-02 입력 · S-03 통계 · S-04 설정 |
| 기능 | **9개** — 추가 · 수정 · 삭제 · 목록 · 월이동 · 통계 · 카테고리관리 · 내보내기/가져오기 · 전체삭제 |
| 시각화 | **가로 막대(비율 바) 1종.** 파이·도넛·꺾은선 금지 |

## 2. ③ 이 채워야 하는 것

| # | 항목 | 비고 |
|---|---|---|
| 1 | 색상 · 간격 · 타이포 · 아이콘 전부 | 화면설계에는 색상값·px·ms·폰트가 **한 건도 없습니다.** 전부 비어 있는 채로 넘깁니다 |
| 2 | **대비비 실제 계산값** | `③ 디자인 완료` 게이트 조건입니다. **"충분해 보임"은 반려**(`team-rules.md:52`) |
| 3 | 최소 터치 영역 수치 | 화면설계 §0-3 이 요구사항으로만 기술 |
| 4 | 인접 버튼 간격 | 특히 S-04 카테고리 행의 `이름변경` ↔ `삭제` — 오탭이 곧 데이터 손실입니다 |
| 5 | 가로 막대의 시각 사양 | **비율 0% 항목을 숨기지 않습니다**(구조설계 §4-3-2). 0% 일 때의 최소 표시 폭을 정해 주십시오 |
| 6 | 카테고리 미선택 안내의 시각 위계 | 문구·표시 시점은 확정됨(기획서 INT-04). **오류로 강조할지 중립 안내로 둘지**가 ③ 결정입니다 |
| 7 | `#jr-unsupported` · `#jr-loading` 의 배치·스타일 | id 이름과 "부팅 성공 시 제거된다"는 규칙만 계약(기획서 INT-14) |
| 8 | 앱 이름 최종 확정 | `정레` 는 **가칭**입니다. 브랜드 영역이라 ② 가 선점하지 않았습니다 |

### 이름 확정 시 주의 2가지

1. 앱 이름은 **S-01 화면 제목에만** 등장합니다. 본문 문구·대화상자·토스트 어디에도 없습니다 — 이름을 바꿔도 문구를 다시 쓸 필요가 없습니다.
2. **백업 파일명에는 앱 이름이 들어가지 않습니다** (`jr-backup-YYYY-MM-DD-HHMM.json`). 이름이 바뀌어도 과거 백업과 접두사가 어긋나지 않도록 구조설계 §5-6-1 이 의도적으로 배제했습니다. 이 규칙을 되돌리지 마십시오.

## 4. 디자인에 직접 영향을 주는 확정 사항 (기획서 §7 발췌)

하위 문서만 보면 **잘못 알게 되는** 항목입니다.

| INT | 확정 | 디자인 영향 |
|---|---|---|
| INT-01 | **S-02(입력 화면)에도 최상단 B 슬롯 배너가 있습니다** | S-02 레이아웃 최상단에 배너 자리를 비워 두십시오. 화면설계 S-02 요소표에는 배너 행이 없지만 §0-2 공통 규칙이 "4개 화면 공통"으로 정의합니다 |

## 5. 배너 3종류 — 시안이 갈립니다

구조설계 §7-8 이 배너를 세 종류로 나눴습니다. **시각 처리가 달라야 합니다.**

| 종류 | 해당 코드 | 닫기 버튼 | 닫은 뒤 |
|---|---|---|---|
| **상태형** (원인이 계속됨) | E-201 · E-202 · E-205 · E-002 | 있음 | 화면을 옮기면 **다시 나타납니다** |
| **사건형** (이미 끝난 일) | E-203 · E-301~E-305 · E-410 · E-604 | 있음 | 이 세션 동안 다시 나타나지 않습니다 |
| **차단형** (닫으면 위험) | **E-307 · E-411** | **없음** | — |

배너는 여러 개를 쌓지 않고 **가장 심각한 것 하나만** 띄웁니다(우선순위는 구조설계 §7-8 마지막 문단). 배너 문구는 최대 3문장이며 가장 긴 것은 E-201 입니다 — 이 문구가 화면 상단에서 잘리지 않는지 확인해 주십시오.

## 6. 대화상자 5종 — 전부 문구 확정됨

| 대화상자 | 단계 | 버튼 |
|---|---|---|
| 나가기 확인 (S-02) | 1 | `계속 입력` / `나가기` |
| 기록 삭제 (S-02) | 1 | `취소` / `삭제` |
| 카테고리 삭제 (S-04) | 1 · **문구 2종**(사용 기록 없음 / N건 있음) | `취소` / `삭제` |
| 가져오기 경고 (S-04) | 1 · 파괴적 동작 · `{N}`·`{M}` 치환 | `취소` / `가져오기` |
| 전체 삭제 (S-04) | **2단계** | 1단계 `취소`/`다음` → 2단계 `취소`/`모두 삭제` |

문구 전문은 화면설계 S-02·S-04 절에 있습니다. 접근성 요구(포커스가 대화상자 내부 안전한 선택지로 이동 · Esc = 취소 · 닫히면 연 버튼으로 복귀)는 화면설계 §0-3 에 확정되어 있습니다.
