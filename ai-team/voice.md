# 🎙️ 음성 — 되는 것과 안 되는 것 (실측)

> **지시 원문 (2026-08-29)**: "항상 마이크를 켜서 박수 두번치고 말로 명령할 수 있게 해줘" / "내가 말로 회의실 열고 보고해라 하면 음성으로 보고했으면 좋겠어"

## 요약
| 원하시는 것 | 가능? | 수단 |
|---|---|---|
| **말로 명령** (음성 입력) | ✅ **가능** | Claude Code 의 `voice` 설정 — `tap` 모드 |
| **항상 마이크 켜 둠** | ❌ 불가 | Claude Code 에 상시 청취 기능이 없습니다 |
| **박수 두 번으로 활성화** | ❌ 불가 | 박수 감지·웨이크워드 기능이 없습니다 |
| **음성으로 보고** (음성 출력) | ⚠️ 원격 불가 · **Windows 로컬만** | `speak-report.ps1` (SAPI) |

## ❓ "tap 모드를 항상 켜 둘 수는 없나" — **이미 항상 켜져 있습니다**
오해하기 쉬운 부분이라 먼저 짚습니다.

`voice.enabled: true, mode: "tap"` 은 **한 번 켜면 계속 켜져 있는 설정**입니다. 세션마다 다시 켜지 않습니다.
「항상 켜 둘 수 없나」의 실제 의미는 **「키를 안 누르고 시작할 수 없나」** 인데, 그건 불가능합니다 — 시작 신호가 필요합니다.

| | |
|---|---|
| 설정이 항상 살아 있는가 | ✅ 예 |
| 마이크가 항상 듣고 있는가 | ❌ 아니오 — 키를 눌러야 시작 |
| 박수 감지기가 하는 일 | **그 키 누름을 대신하는 것뿐** |

즉 `tap` 모드만 켜도 **키 한 번 → 말 → 키 한 번**으로 끝납니다. 박수는 그 키를 손 대신 소리로 누르는 편의 장치입니다.

## ✅ 말로 명령하기 — `tap` 모드
Claude Code 의 음성 입력은 **키를 눌러 시작**합니다. 두 가지 모드가 있습니다.

| 모드 | 동작 |
|---|---|
| `hold` (기본) | 키를 **누르고 있는 동안** 받아쓰기 |
| **`tap`** | **한 번 누르면 시작, 한 번 더 누르면 끝 + 전송** ← 박수 두 번에 가장 가까운 동작 |

```json
// 사용자 설정 (~/.claude/settings.json) — 이 저장소가 아니라 **사용자 기기** 쪽입니다
{ "voice": { "enabled": true, "mode": "tap", "autoSubmit": true } }
```
`/config` 에서 켜는 것이 더 안전합니다. **원격 컨테이너에서 대신 켜 줄 수 없습니다** — 마이크는 사용자 기기에 있고 이 설정도 그쪽 것입니다.

## ❌ 박수 두 번 · 상시 마이크 — 왜 안 되는가
Claude Code 에는 **웨이크워드도, 상시 청취도, 소리 이벤트 감지도 없습니다.** 음성 입력은 항상 **키 입력으로 시작**합니다. 이것은 설정으로 바꿀 수 있는 항목이 아니라 기능의 부재입니다.

### ✅ 그래서 직접 만들었습니다 — `master-listen.py` (D-030, 사용자 지시)
Claude Code 가 못 하는 부분을 **바깥에서** 채웁니다. 마이크를 계속 듣다가 박수 두 번을 감지해 **단축키를 눌러 줍니다.**

```bash
pip install sounddevice                                   # 0단계 (Python 필요)
python ai-team/scripts/master-listen.py --tune         # 1단계 소리 크기 보기
python ai-team/scripts/master-listen.py --setup                # 마이크·음성 점검
python ai-team/scripts/master-listen.py --tune                 # 박수 감도 보정
python ai-team/scripts/master-listen.py --hotkey ctrl+shift+v  # 실제 사용 (깨어난 뒤 누를 단축키)
```

**감지 방식** — 두 조건을 **모두** 요구합니다.
| 조건 | 거르는 것 |
|---|---|
| **온셋** — 직전 블록이 조용했어야 함 | 지속음이 *끝나는* 순간 (말끝) |
| **감쇠** — 40ms 뒤 35% 아래로 떨어져야 함 | 말소리·음악처럼 계속 큰 소리 |
| 불응기 0.12초 · 간격 0.15~1.2초 · 발동 후 3초 재무장 | 한 박수 중복 계수 · 연타 |

**검증한 것 (합성 신호 8종, 전항 통과)**
정상 2회 ✅ 발동 · 1회만 ❌ · 간격 2초 ❌ · 3연타 → 1회만 ✅ · 지속음 ❌ · **말끝+박수1회 ❌** · 말끝 뒤 박수2회 ✅ · 작은 소리 ❌

> 이 검증에서 **결함을 하나 잡아 고쳤습니다.** 처음 판은 「감쇠」만 봐서 **말소리가 끝나는 순간을 박수 1회로** 세었습니다. 온셋 조건을 넣어 해소했습니다.

**⚠️ 아직 검증 못 한 것**: **실제 마이크**. 이 컨테이너엔 오디오 장치가 없습니다. `--tune` → `--test` 를 반드시 사장님 PC 에서 거치십시오. 임계값은 `--factor`(배경 대비 배수) · `--floor`(절대 최소)로 조정합니다.

**선행 조건**: Windows 로컬에 **Python 이 없습니다** (2026-08-07 환경 확인: `git` 만 존재). 설치는 RED(소프트웨어 설치)라 사장님이 직접 하셔야 합니다 — [python.org](https://www.python.org/downloads/) · 설치 시 **Add Python to PATH** 체크.

> ⚠️ 인자 이름은 `ai-team/scripts/master-listen.py` 실물 기준입니다. 예전 문서의 `--key`·`--test`·`--factor`·`--floor` 는 **존재하지 않는 인자**였습니다 (3차 감사 중대-4 정정). 그 밖에 `--say` · `--device` · `--list` · `--quiet` 가 있습니다.

**어떤 키를 줘야 하나**: Claude Code 의 음성 입력 단축키입니다. `/config` 에서 voice 를 켠 뒤 확인하시고, 그 조합을 `--key` 에 넣으십시오. 모르면 `--test` 로 감지만 확인하셔도 됩니다.

## ✅ 음성 응답 루프 — `master-voice.ps1` (D-030)
박수 → 말로 명령 → **마스터가 음성으로 답하는** 한 바퀴입니다.

```
👏👏  박수 두 번        master-listen.py 가 단축키 전송
🎙️  말로 명령          Claude Code 받아쓰기 (tap 모드)
🎩  마스터가 답함       화면 + ai-team/voice-out/<시각>-<주제>.txt 원고 작성 → 커밋·푸시
🔊  낭독               사장님 PC 의 master-voice.ps1 이 pull → SAPI 로 읽음
```

```powershell
.\ai-team\scripts\master-voice.ps1                # 20초마다 확인, 새 보고문 낭독
.\ai-team\scripts\master-voice.ps1 -Once          # 한 번만
.\ai-team\scripts\master-voice.ps1 -IntervalSec 10 -Rate 1
```
- 이미 읽은 파일은 다시 읽지 않습니다 (`.spoken`, git 추적 안 함)
- **읽은 뒤에** 기록하므로 중간에 끊기면 다시 읽습니다 (놓치는 것보다 낫습니다)
- **지연은 폴링 주기만큼입니다. 실시간이 아닙니다**
- ⚠️ **미검증** — PowerShell 없는 컨테이너에서 작성

**낭독 원고 규칙** (마스터가 지킵니다): 표·코드블록·기호 없이 · 짧은 문장 · 30초 안팎 · "마스터입니다."로 시작. 자세한 건 화면으로.

## ⚠️ 왜 원격에서 직접 소리를 못 내는가
```
espeak · espeak-ng · say · festival · spd-say · pwsh · powershell → 전부 없음
/dev/snd → 없음 (오디오 장치 부재)
```
컨테이너는 클라우드에 있습니다. **거기서 소리를 내도 사용자에게 닿지 않습니다.**

**대신**: 보고문은 원격이 만들고 **읽는 것은 사용자 PC 의 Windows SAPI** 가 합니다.
```powershell
.\ai-team\scripts\speak-report.ps1                 # STATE.md 요약 낭독
.\ai-team\scripts\speak-report.ps1 -Path <파일>
.\ai-team\scripts\speak-report.ps1 -Save out.wav   # 소리 대신 파일로
```
표·코드블록을 걷어내고 문장만 읽습니다. 한국어 음성이 없으면 경고합니다(설정 > 시간 및 언어 > 음성).
⚠️ **미검증** — 이 컨테이너에 PowerShell 이 없어 문법 검토만 했습니다.

## 📱💻 핸드폰 ↔ 컴퓨터 — 팀은 **이미 오갑니다** (D-031)
> **지시 원문 (2026-08-29)**: "마이크는 컴퓨터 마이크가 잇고 내 핸드폰이랑 컴퓨터랑 오가면서 음성이 오가고 이 팀도 오가면 좋겠어"

**팀이 오가는 것은 이미 되고 있습니다.** 새로 만들 것이 없습니다.

| 기기 | 팀을 어떻게 만나나 | 상태는 어떻게 아나 |
|---|---|---|
| 💻 컴퓨터 (Claude Code) | 저장소를 열면 `.claude/agents/` 31명 자동 등록 | `SessionStart` 훅이 STATE + 로스터 자동 출력 |
| 📱 핸드폰 (claude.ai 앱) | **같은 원격 컨테이너 = 같은 저장소.** 31명 그대로 | 같은 훅이 그대로 뜹니다 |
| 어느 쪽이든 | | `supabase-sync.py status` 한 줄 (D-023) |

핸드폰에서 대화창을 열면 **여기와 같은 컨테이너**에 붙습니다. 팀도, 규정도, 상태도 그대로입니다.
음성 **입력**도 핸드폰이 더 쉽습니다 — claude.ai 앱에 마이크가 있어 **박수 감지기도 Python 도 필요 없습니다.**

### 🎩 음성 브리핑 콘솔 — 설치 없이 양쪽에서
문제는 **음성 출력**이었습니다. `speak-report.ps1` 은 Windows 전용이라 핸드폰에서 못 씁니다.
→ **브라우저 자체 음성 엔진**을 쓰는 페이지를 만들었습니다. 핸드폰·PC 어디서 열어도 **설치가 필요 없습니다.**

| | |
|---|---|
| 하는 일 | 브리핑을 **소리로 읽음** · 팀 31명 명단 · 차단 목록 · **말을 글자로 받아씀** |
| 필요한 것 | 브라우저만. Python·PowerShell 불필요 |
| 못 하는 일 | 받아쓴 말을 **마스터에게 직접 못 보냅니다** — 아티팩트는 바깥으로 요청을 보낼 수 없습니다(CSP). 복사해 붙여넣거나 Claude 앱에 대고 말하십시오 |
| 아이폰 | 소리는 화면을 한 번 누른 뒤 납니다. 받아쓰기는 사파리에서 안 될 수 있습니다 |
| 갱신 | 상태가 바뀌면 **마스터가 다시 발행**합니다 (페이지가 스스로 갱신되지는 않습니다) |

원본: `ai-team/console/master-console.html` (저장소에 있으므로 함께 버전 관리됩니다)

| 상황 | 쓸 것 |

## 정직하게
「항상 마이크」와 「박수 두 번」은 **지금 구조에서 제공할 수 없습니다.** 되는 척하지 않습니다.
가장 가까운 것은 **`tap` 모드**(한 번 눌러 말하고, 한 번 더 눌러 전송)이며, 이건 지금 바로 켤 수 있습니다.
