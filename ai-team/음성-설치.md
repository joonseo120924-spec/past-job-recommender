## 0단계 · 창 열기와 붙여넣기 (제일 먼저)

### 🔴 지금 뜬 창이 어떤 창인지부터 보십시오
화면 맨 앞 글자를 보시면 압니다.

| 보이는 것 | 무슨 창인가 | 명령을 붙여넣어도 되나 |
|---|---|---|
| `C:\Users\User>` | **명령 프롬프트 (cmd)** | ✅ **여기가 맞습니다** |
| `PS C:\Users\User>` | PowerShell | ✅ 여기도 됩니다 |
| `>>>` | **파이썬 대화창** | ❌ **여기 아닙니다** |

> **`>>>` 가 보이면** 파이썬 자체를 켠 것입니다. 여기에 `pip install ...` 을 넣으면 `SyntaxError` 가 납니다.
> `exit()` 를 치고 Enter → 창을 닫고 아래대로 다시 여십시오.

### 올바른 창 여는 법
1. 키보드에서 **`윈도우키` + `R`** 을 함께 누릅니다
2. 작은 상자가 뜨면 **`cmd`** 라고 칩니다
3. **Enter**

`C:\Users\...>` 로 시작하는 검은 창이 뜨면 준비 완료입니다.

### 붙여넣는 법
1. 이 문서에서 명령을 **드래그해 선택** → **`Ctrl` + `C`**
2. 검은 창을 **한 번 클릭**해 활성화
3. **`Ctrl` + `V`** — 안 되면 **마우스 오른쪽 버튼 클릭** (구형 창은 오른쪽 클릭이 곧 붙여넣기입니다)
4. **Enter** 를 눌러야 실행됩니다 — 붙여넣기만 하면 아무 일도 일어나지 않습니다

> 명령 **한 줄씩** 붙여넣고 Enter 하십시오. 여러 줄을 한꺼번에 넣으면 중간에 멈출 수 있습니다.

### 알아두시면 편한 것
| | |
|---|---|
| 글자가 안 보임 | 정상입니다. 비밀번호 입력이 아니면 그냥 안 보이는 게 아니라 **떠 있습니다** — 창을 클릭했는지 확인 |
| 되돌리고 싶다 | **`Ctrl` + `C`** (실행 중단) |
| 창 닫기 | `exit` + Enter, 또는 창 오른쪽 위 X |
| 방금 친 명령 다시 | **위쪽 화살표 키 ↑** |

## 1단계 · 파이썬 설치 (5분, 한 번만)

1. https://www.python.org/downloads/ 접속 → 노란 **Download Python** 버튼
2. 받은 파일 실행
3. 🔴 **첫 화면 맨 아래 「Add python.exe to PATH」에 반드시 체크** — 이걸 놓치면 나중에 "python은 명령이 아닙니다" 가 뜹니다
4. **Install Now** → 끝나면 Close

**확인**: 시작 → `cmd` 입력 → 검은 창에서
```
python --version
```
`Python 3.13.x` 처럼 나오면 됩니다.

> ❌ **"python은(는) 내부 또는 외부 명령이 아닙니다"** → PATH 체크를 놓치신 겁니다.
> 설치 파일을 다시 실행 → **Modify** → Next → **Add Python to environment variables** 체크 → Install

## 4단계 · 점검 — 소리가 나는지

```cmd
python ai-team\scripts\master-listen.py --setup
```

이렇게 나오면 정상입니다.
```
   ┌─────────────────────────────────────────────┐
   │   J A R V I S                               │
   │   AI 앱 개발팀 · 총괄                        │
   └─────────────────────────────────────────────┘

   ● 마이크          마이크 (Realtek(R) Audio)
   ● 음성 출력        Windows SAPI
   ○ 단축키          미설정 — 깨우기만 합니다
   ● 대기 보고문       1건
```
그리고 **"마스터입니다. 소리가 들리시면 준비가 된 것입니다."** 가 들려야 합니다.

| 증상 | 해결 |
|---|---|
| 마이크가 ○ | `python ai-team\scripts\master-listen.py --list` 로 번호 확인 → `--device 1` |
| 소리가 안 남 | 스피커 볼륨 · Windows 설정 > 시간 및 언어 > 음성 |
| 발음이 어색함 | 위 설정에서 **한국어 음성** 추가 |

## 5단계 · 박수 감도 맞추기 (2분)

```cmd
python ai-team\scripts\master-listen.py --tune
```
막대가 실시간으로 움직입니다. **조용히 있다가 박수를 다섯 번쯤** 치십시오.

```
   배경 180    현재 8420  ████████████████████████████████████████
   피크 8420 (기준 1500)
```

`Ctrl+C` 로 멈추면 권장값이 나오고, **`y`** 를 누르면 저장됩니다.

| 증상 | 해결 |
|---|---|
| 박수가 안 잡힘 | 마이크에 가까이 · 더 세게 · `--tune` 다시 |
| 아무 소리에나 반응 | `master-listen.config.json` 의 `floor` 를 **올리십시오** (1500 → 3000) |

## 7단계 · 받아쓰기까지 연결 (선택)

여기까지는 "부르면 대답"입니다. **말로 명령**까지 가려면 단축키를 알려주셔야 합니다.

1. Claude Code 에서 `/config` → **voice** 를 켜고 **tap** 모드로
2. 그 단축키를 마스터에게 알려줍니다
```cmd
python ai-team\scripts\master-listen.py --hotkey ctrl+shift+v
```
3. 다시 기동하면 — 👏👏 → "네, 사장님." → **받아쓰기 자동 시작** → 말씀하시면 됩니다

> 인사가 끝나고 0.6초 뒤에 키를 누릅니다. 자기 목소리가 받아쓰기에 섞이지 않게 한 것입니다.

## 명령 요약
| 명령 | 하는 일 |
|---|---|
| `master-listen.py` | 기동 (박수 대기) |
| `master-listen.py --setup` | 마이크·음성 점검 |
| `master-listen.py --tune` | 박수 감도 보정 |
| `master-listen.py --say "안녕"` | 말하기만 시험 |
| `master-listen.py --list` | 마이크 목록 |
| `master-listen.py --hotkey ctrl+shift+v` | 단축키 저장 |
| `master-listen.py --quiet` | 소리 없이 감지만 |

설정은 `ai-team/scripts/master-listen.config.json` 에 저장됩니다. 인사말도 여기서 바꾸실 수 있습니다.
