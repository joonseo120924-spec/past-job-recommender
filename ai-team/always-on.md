# 「항상」 규칙 — 4가지 상시 자동화 (D-026)

> **지시 원문 (2026-08-29)**: "노션 페이지 업데이트 하고 항상 슈퍼베이스에 저장하고 중간중간 마다 항상 git hub에 올리고 항상 에이아이 에이전트가 팀에 있아사 항상 부를 수 있게 해"

## 왜 「기억」이 아니라 「훅」인가
마스터가 규정을 아는 것과 **매번 실제로 실행되는 것**은 다릅니다. 이 팀의 사고는 전부 후자에서 났습니다.

| 사고 | 마스터가 몰라서? |
|---|---|
| 08-16~28 **13일간 커밋 0건** | 아니오. 규정은 있었고 실행이 안 됐습니다 |
| 08-10~15 로컬·원격 **6일 분기** | 아니오. 양쪽 다 "기록한다"는 규정을 갖고 있었습니다 |
| 08-11 노션 상단 표 미갱신 → **치명 반려** | 아니오. 규약에 있었지만 그 실행에서 빠졌습니다 |

그래서 이 4가지는 **하네스가 강제하는 훅**으로 넣었습니다. 마스터가 잊어도 돕니다.

---

## 규칙 1 — 슈퍼베이스에 항상 저장 ✅ 완전 자동
| | |
|---|---|
| 방식 | **`Stop` 훅** — 마스터가 말을 멈출 때마다 `checkpoint.sh` 가 `supabase-sync.py push` |
| 주기 | **매 턴.** "중간중간"이 여기서 실현됩니다 |
| 실패 시 | 세션을 막지 않고 `✗ 실패` 로 보고합니다. 조용히 넘어가지 않습니다 |
| 수동 | `python3 ai-team/scripts/supabase-sync.py push` |

**진행 중 이벤트**는 별개입니다. 회의실 규정(`meeting-room/SKILL.md` 4절)이 호출·승인·반려·결정·막힘마다 `supabase-sync.py event` 를 남기게 합니다 — 이건 훅이 아니라 규정이라 마스터가 지켜야 합니다.

## 규칙 2 — GitHub에 중간중간 항상 올리기 ✅ 완전 자동
| | |
|---|---|
| 방식 | 같은 `Stop` 훅. 변경이 있으면 `[checkpoint]` 커밋 후 푸시 |
| 커밋 메시지 | `[checkpoint] 자동 저장 — YYYY-MM-DD HH:MM KST` — **사람이 낸 커밋과 구별됩니다** |
| 푸시 실패 | 2·4·8초 재시도. 끝내 실패하면 **커밋은 남기고** 실패를 보고합니다 |
| 안 하는 경우 | 변경 없음 · 앞선 커밋 없음 |

> ⚠️ **자동 커밋의 대가**: 작업 중간 상태도 커밋됩니다. 이 팀에는 그게 맞습니다 — 13일 공백의 반대편 위험(지저분한 히스토리)이 훨씬 쌉니다. `[checkpoint]` 태그로 나중에 정리할 수 있습니다.

## 규칙 3 — 노션 항상 업데이트 ⚠️ 부분 자동 (정직하게)
**「항상」을 기술적으로 보장할 수 없습니다.** 노션 MCP 는 세션마다 붙기도 하고 안 붙기도 합니다. 07:07 Routine 에는 커넥터가 안 붙을 수 있다는 것이 이미 확인된 제약입니다 (`notion-sync.md`).

| 단계 | 자동? |
|---|---|
| 큐에 먼저 쓴다 (`notion-queue/<날짜>.md`) | 규정 — `daily-app` 5단계 |
| 노션에 반영 (항목 append + **상단 표 갱신**) | **도구가 있는 세션에서만** |
| **미반영 건수 감시** | ✅ **`Stop` 훅이 매 턴 셉니다** |

훅은 `🔴 미반영 N건` 을 매 턴 눈앞에 띄웁니다. 반영을 대신 해주지는 못하지만 **잊히지는 않습니다.** 13일 공백이 조용했던 이유가 바로 이 감시가 없어서였습니다.

조직·규정이 바뀐 날은 「작업 일지」뿐 아니라 **팀 홈 · 팀원 명세 · 팀 규정** 페이지도 갱신합니다 (`notion-sync.md` 「대상 노션 페이지」).

## 규칙 4 — 에이전트를 항상 부를 수 있게 ✅ 자동 + 실측
에이전트 31명은 **`.claude/agents/` 에 파일로** 있습니다. 이 저장소를 연 Claude Code 세션이면 **자동으로 등록**되어 이름으로 바로 호출됩니다.

| | |
|---|---|
| 방식 | **`SessionStart` 훅** — 세션이 열릴 때마다 `STATE.md` + **로스터**를 띄웁니다 |
| 로스터 | `roster.sh` 가 **`.claude/agents/` 를 실측해** 출력합니다 |
| 왜 실측인가 | 손으로 관리한 "tools 금지 역할 10개" 목록이 실제로는 11개였습니다 (2026-08-29 발견). **목록은 드리프트합니다. 파일은 안 합니다** |
| 누락 감지 | 조직도에 있는데 파일이 없으면 `⚠️ 없음:` 으로 표시됩니다 |

```bash
ai-team/scripts/roster.sh    # 지금 부를 수 있는 사람 전원
```

## 훅 구성 (`.claude/settings.json`)
| 이벤트 | 명령 | 언제 |
|---|---|---|
| `SessionStart` | `cat ai-team/STATE.md` | 세션 시작 |
| `SessionStart` | `ai-team/scripts/roster.sh` | 세션 시작 |
| `Stop` | `ai-team/scripts/checkpoint.sh --hook` | **마스터가 말을 멈출 때마다** |

전부 `|| true` 로 감싸 **세션을 막지 않습니다.** 훅을 보거나 끄려면 `/hooks`.
