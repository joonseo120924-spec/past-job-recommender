# 노션 동기화 규약

> 사용자 지시(2026-08-10): **"여기서 자동화 시킨거 노션에 저장한뒤 다음날 보고 이어서 해 항상 한거 노션에 정리해"**

## 왜 큐를 거치는가
07:07 정기 실행은 Claude Routine 이 이 대화창을 깨우는 방식인데, **그 실행에 노션 커넥터가 붙지 않을 수 있습니다** (조직 설정상 Routine에 커넥터를 첨부할 수 없음). 노션에 못 쓰는 날 기록이 그냥 사라지면 "다음날 보고 이어서" 가 끊깁니다.

그래서 **기록은 항상 저장소에 먼저 남기고, 노션 반영은 가능한 시점에 밀린 것까지 몰아서** 합니다.

## 정본은 어디인가
| | 역할 |
|---|---|
| **저장소** (`ai-team/`) | **실제 상태.** 충돌 시 이쪽이 맞습니다 |
| **노션** 「📓 작업 일지」 | **세션 간 기록·인수인계.** 사람이 읽는 곳 |

어긋나면 저장소를 기준으로 노션을 고치고, 어긋났다는 사실을 그날 항목에 적습니다.

## 대상 노션 페이지
| 페이지 | ID | 갱신 내용 |
|---|---|---|
| 📓 작업 일지 | `3b750286-df80-8173-a09e-f8dc7712e713` | 날짜별 항목 **append** + 상단 "현재 상태" 표 갱신 |
| 🏢 AI 앱 개발팀 (홈) | `3b750286-df80-8188-b56b-e24bf6d49c40` | 조직·규정이 바뀐 날만 |
| 👥 팀원 20명 역할 명세 | `3b750286-df80-814b-8c9f-eb6ed22f7dce` | 역할이 바뀐 날만 |
| 📜 팀 규정 | `3b750286-df80-81df-9d1f-fe04c105c200` | 규정이 바뀐 날만 |

**기존 항목을 지우지 않습니다.** `insert_content` + `position: end` 로 덧붙입니다.

## 절차

### 1. 큐에 먼저 쓴다 (항상)
`ai-team/notion-queue/<YYYY-MM-DD>.md`

```markdown
상태: 대기            ← 노션 반영되면 "반영됨 <ISO 시각>" 으로 바꿈
대상: 📓 작업 일지
---
# YYYY-MM-DD · 사이클 N · M일차 (원격 컨테이너 자동 실행)

**🟡 YELLOW**: (없으면 "없음")

## 한 일
## 승인 / 반려
## 남은 오류
## 감사관 판정
## 커밋
## 내일 이어받을 지점
```

### 2. 노션 도구가 있으면 밀린 것부터 반영
```
상태: 대기  인 파일을 날짜 오름차순으로 →
notion-update-page(page_id=…, command="insert_content", position={"type":"end"}, content=<--- 아래 본문>)
→ 성공하면 상태 줄을 "반영됨 <시각>" 으로 수정
```
그다음 「📓 작업 일지」 상단 "현재 상태" 표를 오늘 값으로 `update_content` 합니다.

### 3. 노션 도구가 없으면
큐에 그대로 두고 `SESSION-LOG.md` 에 **"노션 미동기화 N건: <날짜 목록>"** 을 적습니다. 다음 실행이 자동으로 밀린 것까지 반영합니다.

## 하지 않을 것
- 노션에 못 썼는데 썼다고 보고하지 않습니다
- 큐 파일을 지우지 않습니다 (반영 후에도 남겨 감사 흔적으로 씁니다)
- 확인 못 한 항목을 "정상"으로 쓰지 않습니다
