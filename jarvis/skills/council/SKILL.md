# council — 팀 회의실

앱 사이클 밖의 안건으로도 AI 앱 개발팀을 부릅니다. 6본부는 원래 앱을 만들려고
짠 조직이지만, 껍질을 벗기면 **조사 → 설계 → 표현 → 실행 → 검증 → 운영**이라
어떤 주제에도 씌울 수 있습니다.

- **① 전략과 ⑤ 품질은 상시 배석입니다.** 무엇을 할지 정하는 자리와, 틀린 곳을 찾는
  자리는 안건을 가리지 않습니다 (규정: 모든 산출물은 검토를 1회 이상).
- 나머지 본부는 안건의 말에 걸릴 때만 부릅니다.
- 자리표(어느 본부·누가 파트장·실무자·무엇을 산출)를 `outputs/council-…` 에 남깁니다.
- 파트장만 승인권을 가지고, 감사관이 마지막에 판정한다는 규정을 안건마다 다시 씁니다.

예: "팀 소집해서 유튜브 채널 어떻게 키울지 논의해줘" · "팀 불러서 이사 준비 정리하자"
