# status — 현재 상황 보고

한 번의 물음에 지금 아는 것을 전부 정리해 말합니다.

1. 시스템 — CPU · 메모리
2. 볼트 — 노트 수 · 링크율
3. 하루 흐름 — 몇 개 실행했는지
4. 열린 할 일 건수
5. 지표 — 최근 스냅샷과 변화율
6. 에이전트팀 — 사이클·단계·차단 건수 (한 줄)

측정할 수 없는 값은 "측정 불가"라고 말합니다. 빈칸을 0으로 채우지 않습니다.
