# agents — 노션 AI 앱 개발팀 현황

노션 정본(팀 홈 · 작업 일지 · 팀원 명세 · 팀 규정)에서 끌어온 상태를
`vault/data/agent-team.json` 에서 읽어 보고합니다.

- 사이클 번호·일차·현재 단계
- 앱별 상태 (동결 / 진행 중)와 사유
- 감사관 판정과 치명·중대 건수
- 사용자 지시가 필요한 🔴 차단 목록
- 다음에 이어받을 지점

스냅샷이 하루 넘게 지났으면 **며칠 지났는지 함께 말합니다.** 오래된 상태를
최신인 척하지 않습니다.

`NOTION_TOKEN` 이 있으면 `POST /api/notion/sync` 로 노션에서 다시 읽어
`wiki/` 미러와 스냅샷 시각을 갱신합니다. 토큰이 없어도 스냅샷으로 답합니다.
